**astrogo requires `github.com/andybalholm/brotli` v1.2.8, past GO-2026-6888.** The advisory is excessive memory allocation when decompressing a crafted stream, and `remote`'s HTTP backend decodes brotli responses through that library, so a source sending a crafted body could make a download allocate without bound. A program importing astrogo can no longer select an affected version.
